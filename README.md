# Quá trình Hấp thụ Khoáng ở Thực vật

Bài thuyết trình tương tác "Tour Làng Khoáng" — Đoàn Trần Yến Linh, 74CLC Khoa Sinh Học.

Mở `index.html` bằng trình duyệt để xem. Phím tắt: → / Space bước tiếp · ← lùi · 1–5 thêm phiếu · H hồ sơ vụ án · T đồng hồ · F toàn màn hình · ? trợ giúp.

Số phiếu bình chọn đang là **dữ liệu mẫu** để xem thử — bấm "Phiếu mẫu ✕" ở thanh dưới để xoá về 0 trước khi dạy thật.
